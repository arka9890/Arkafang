Bisakah kamu jelaskan cara kerja React Server Components (RSC) dengan analogi sederhana dan contoh kode minimal penggunaan data fetching?

10:42 AM
auto_awesome
Claude 3.5 Sonnet · 1.2s

Tentu! Bayangkan React Server Components (RSC) seperti dapur restoran berfasilitas lengkap:

  • check_circle Bahan Baku di Dapur: Server menyiapkan semua data mentah dan memasaknya langsung tanpa mengirim resep rahasia ke meja tamu.
  • check_circle Hidangan Jadi ke Tamu: Klien hanya menerima representasi UI bersih tanpa paket JavaScript berat untuk memproses data tersebut.
  • check_circle Zero Client Bundle: Dependensi berat (seperti parsing markdown atau query database) tetap tinggal di server.
code UserProfile.jsx 
// Server Component (Async native)
export default async function UserProfile({ userId }) {
  const user = await db.users.findUnique({ id: userId });

  return (
    <section className="card">
      <h2>{user.name}</h2>
      <p>{user.role}</p>
    </section>
  );
}
